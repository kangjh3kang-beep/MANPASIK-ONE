# IEC 62366-1 사용적합성 엔지니어링 계획 (Usability Engineering Plan)

> **문서번호** MPS-HFE-PLAN-v1.0 · **표준** IEC 62366-1:2015+A1:2020 · IEC 62304 Class B
> **적용 범위** 만파식 POCT 플랫폼 — 모바일 앱(CH3-PAT) + 리더기 인터페이스

---

## 1. 사용 환경 및 사용자 프로파일

### 1.1 의도된 사용자

| 사용자 그룹 | 연령 | 디지털 문해력 | 빈도 | 핵심 과업 |
|-----------|------|-------------|------|----------|
| 일반 사용자 (P1) | 20~60 | 중~상 | 주 2~5회 | 측정, 결과 확인, 코칭 |
| 만성질환자 (P2) | 40~80 | 하~중 | 매일 1~3회 | 측정, 투약 확인, 주치의 공유 |
| 부모/보호자 (P3) | 25~45 | 중~상 | 주 1~3회 | 아동 측정, 가족 모니터링 |
| 고령자 (P2 하위) | 65~85+ | 하 | 매일 | 단순 측정, 결과 확인 (elder 모드) |

### 1.2 사용 환경

| 환경 | 조건 | UX 고려사항 |
|------|------|-----------|
| 가정 (1차) | 조용, 앉은 자세, Wi-Fi/LTE | 오프라인 대비, 밝기 가변 |
| 이동 중 | 진동, 소음, 한 손 조작 | 대형 타깃(≥44px), 단순 플로우 |
| 의료기관 (보조) | 의료진 감독 | 전문 모드, FHIR 연동 |

### 1.3 사용 관련 위험 (Use-Related Hazards)

| ID | 위험 | 심각도 | 완화 |
|------|------|--------|------|
| UH-01 | 카트리지 잘못 삽입 | 중간 | NFC 자동 인식 + 가이드 애니메이션 |
| UH-02 | 시료 부족/과다 | 높음 | 용량 표시 일러스트 + 경고 |
| UH-03 | 결과 오해 (수치 오독) | 높음 | 3중 인코딩(색+아이콘+텍스트) + 평이 언어 |
| UH-04 | 긴급 상황 미인지 | 최고 | 위험 알림 즉시 전화면 표시 + 음성 |
| UH-05 | 오프라인 상태 미인지 | 중간 | 오프라인 배지 상시 표시 |
| UH-06 | AI 결과 과신 | 높음 | 불확실성 의무 표시 + "AI 참고정보" 고지 |
| UH-07 | 고령자 터치 실패 | 중간 | elder 모드 타깃 ≥56px |

## 2. 사용적합성 시험 계획

### 2.1 형성적 평가 (Formative)

| 항목 | 내용 |
|------|------|
| 참가자 | n=8~12, P1/P2/P3 혼합, 연령 25~75 |
| 과업 | 카트리지 인식→측정→결과 확인→코칭 확인 (J1 핵심 경로) |
| 측정 | 과업 완료율, 오류 수, 과업 소요 시간, SUS 설문 |
| 환경 | 시뮬레이터 + 프로토타입 앱 |
| 판정 | 완료율 ≥80%, 치명 오류 0건 |

### 2.2 총괄적 평가 (Summative)

| 항목 | 내용 |
|------|------|
| 참가자 | n=15~20, 고령자 5명 이상 포함 |
| 과업 | J1 전체 + 긴급 알림 대응 + elder 모드 측정 |
| 측정 | 과업 완료율, 오류 분류 (use error/close call/difficulty) |
| 수용 기준 | 완료율 ≥90%, 치명 use error 0건, SUS ≥68 |
| 시기 | Phase 3 완료 후, 규제 제출 전 |

## 3. UI 설계 원칙 (기존 MDS 정합)

- 결과 3중 인코딩: 색채 단독 금지 → 수치 + 아이콘 동반
- 1화면 1행동 (특히 elder/child 모드)
- 신뢰도/불확실성 항상 동반 (과대표현 금지)
- 오프라인 상태 상시 표시
- 긴급 알림은 모든 모드에서 전화면 표시
